# 🐍 1. Python

## A. Multiple Assignment

### Assigning Multiple Values to Multiple Variables

```python
num1, num2, num3 = 10, 20, 30

print("Number 1:", num1)
print("Number 2:", num2)
print("Number 3:", num3)
```

### Assigning the Same Value to Multiple Variables

```python
num1, num2, num3 = 10, 10, 10

print("Number 1:", num1)
print("Number 2:", num2)
print("Number 3:", num3)
```

Another example:

```python
num1, num2, num3 = 355, 355, 355
```

---

## B. `id()` Function

The built-in `id()` function returns the identity of an object.

```python
num1 = 10
num2 = 20
num3 = 30

print(id(num1), id(num2), id(num3))
```

When multiple variables refer to the same object, their identity values will be the same.

## C. Swapping Variables

### Classroom Code

```python
a, b = 10, 20

print("Before Swapping:", a, b)

a, b = b, a

```

**Output:**


## E. Python Tokens

A token is the smallest meaningful unit of source code.

### Types of Tokens

| Type | Description | Example |
|---|---|---|
| Keywords | Reserved words | `if`, `else`, `for` |
| Identifiers | Names of variables, functions and classes | `student_name` |
| Literals | Constant values | `10`, `"Python"` |
| Separators | Symbols used to separate/organize code | `()`, `[]`, `{}`, `,`, `:` |
| Operators | Symbols used to perform operations | `+`, `-`, `=`, `*` |

Example:

```python
num = 10
```

- `num` → Identifier
- `=` → Operator
- `10` → Literal

## F. Variables

A variable is a name that refers to data/object used within a program.

```python
age = 22
age = 23
```

The value referred to by the variable can be changed by assigning another value.

### Variable Naming Rules

- Names may start with a letter or underscore.
- Names cannot start with a number.
- Spaces are not allowed.
- Python keywords cannot be used as variable names.
- Names are case-sensitive.

Examples:

```python
student_name = "Ganesh"
age2 = 22
_name = "Ala"
```

### Divisibility Rules

| Number | Rule |
|---|---|
| 2 | Last digit is even |
| 3 | Sum of digits is divisible by 3 |
| 4 | Last two digits are divisible by 4 |
| 5 | Last digit is 0 or 5 |
| 8 | Last three digits are divisible by 8 |
| 9 | Sum of digits is divisible by 9 |
| 11 | Difference of alternate digit sums is 0 or a multiple of 11 |
| 12 | Divisible by both 3 and 4 |

### Prime and Composite Numbers

- Prime number: Exactly two factors, 1 and itself.
- Composite number: More than two factors.
- Factor: Divides a number exactly.
- Multiple: Obtained by multiplying a number by an integer.

### Handshake Formula

For `n` people shaking hands with each other once:

\[
\frac{n(n-1)}{2}
\]

Example for 4 people:

\[
\frac{4(4-1)}{2}=6
\]

### Leap Year Rule

- A year divisible by 4 is generally a leap year.
- Century years must be divisible by 400.

Examples:

- 2024 – Leap Year
- 2025 – Not a Leap Year
- 1900 – Not a Leap Year
- 2000 – Leap Year
