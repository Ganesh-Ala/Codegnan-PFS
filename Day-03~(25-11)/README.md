## 🐍 1. Python

### Topic: Personal Introduction Using `print()`

Today's classroom exercise involved writing a Python program to display personal information, educational background, technical skills, and profile links.

### Code Practiced

```python
print("This is My Introduction.")
print("------------------------")
print("Email: yourname@gmail.com")
print("Batch: PFS-72")
print("Module: PYTHON")
print("Timings: 9am to 11am")
print("------------------------")
print("My Education Background")
print("B.Tech, CSE-DataScience")
print("My GitHub URL: https://github.com/Ganesh-Ala")
print("My LinkedIn URL: https://www.linkedin.com/in/ganesh-ala/")
print('''My Technical Skills:Python, MySQL, FastAPI, Flask, AI Tools.
''')
```

### Concepts Covered

- `print()` function
- Displaying text/output
- String values
- Using multiple `print()` statements
- Separating output using lines
- Multiline strings using triple quotation marks

### Learning Outcome

Learned how to create a simple Python program that displays personal information in an organized format.
